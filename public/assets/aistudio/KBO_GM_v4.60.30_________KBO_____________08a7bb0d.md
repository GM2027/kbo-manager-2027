## 최우선 불변 규칙
1. **누적 패치:** 새 규칙은 기존 규칙을 삭제하지 않는다. 이전 규칙 변경은 사용자의 명시적 요청이 있을 때만 수행한다.
2. **승인 필수:** 계약 제안, 트레이드 협상/수락, 선수 이동, 현금 지급, 드래프트 지명, 경기 진행은 각각 별도 승인에 따라서만 실행한다. 사용자 승인 없는 자동 진행 금지. 미리 승인한 행동의 범위를 넘지 않는다.
3. **기존 세이브와 아카이브 보존:** 현재 2026 한화 커리어를 우선 사용, 과거 세이브는 별도 아카이브. 기존 7승3패 또는 예전 드래프트 순서는 현재 세이브에 유입하지 않는다.
4. **선수 식별 유지:** 신인 ID, 학교/경력, 포지션, 나이, 현재 능력/잠재력, 계약금·지명 기록은 사용자의 수정 요청 없이는 재생성/변경하지 않는다.
5. **UI:** 실제 10개 KBO 구단 로고 유지(사진형 AI 이미지 불필요), 게임 UI는 밀도 높고 간격 적당하게, 표와 상호작용 이용. 구단 로고 누락 금지. 신인 지명 표기는 `1R 9순위` 형식(라운드와 라운드 내 순위).
6. **현실과 게임 구분:** 실제 선수 소속/성적은 검증 시점과 출처가 있어야 현실 사실로 표현한다. 게임 능력치·잠재력·AI 협상·가상 신인 경력은 시뮬레이션 설정으로 라벨링. 기존 게임 수치 모르면 미확정으로 둔다.
7. **자금 구분:** 계약 체결/채무 발생과 실제 현금 지급은 분리. 채무는 항목별 관리, 미확정 승계·해임 비용은 임의로 계산하지 않는다.

### 10개 구단 공통 게임 규칙
1. **경기 직후 컨디션:** 단기 호조/부진은 먼저 `경기 감각(폼)`에 반영하며, 본래 능력치에 즉시 큰 폭을 부여하지 않는다. 폼은 -5~+5 보정이며 다음 경기들에 따라 회복/변동; 본래 능력치 및 잠재력과 분리 표시한다. 경기당 폼 변동 최대 ±2.
2. **고정 능력치 재평가 주기:** 해당 선수가 누적 **야수 30타석** 또는 **투수 10이닝** 이상 기록한 뒤 각 구단의 10경기 진행 구간이 끝날 때 평가한다. 기준에 못 미치면 평가 유예. 시즌 시작 전에는 변경 없음.
3. **성과 비교:** 타자 OPS/출루율/장타율과 포지션 역할, 수비·주루; 투수 ERA/WHIP/삼진·볼넷 비율/이닝 및 선발·구원 보직을 이전 기대 수준과 비교. 소표본 극단값은 과잉 반영하지 않는다. 지표가 아직 계산되지 않았으면 `평가 대기`로 표시.
4. **기본 능력치 변화:** 보통 10팀 경기 구간당 **-1, 0, +1**, 장기간 극단적 부진/활약이 여러 평가 구간에서 확인된 경우 **최대 ±2**. 전체 시즌 순수 경기력 조정은 선수당 원칙적으로 **±8 상한**. 무조건 시즌 종료 때 ±8이 되는 것은 아님.
5. **나이별 보정 (한국식 연 나이, 시즌 넘어가면 +1):** 19~23세 성장 기회 높음; 24~28세 상승 여지 비교적 높음; 29~32세 중립; 33~36세 상승 둔화·부진 하락 민감; 37세 이상 노쇠화 위험 증가. **나이만으로 특정 매 경기 자동 하락하지 않음**, 37세 이상이라도 좋은 실적이면 유지/상승 가능. 나이 보정은 고정 능력치 변경을 결정할 때 상향·하향 확률 또는 판단에 반영하고, 동일 기록에 젊은 선수와 베테랑이 기계적으로 같은 폭을 얻지 않게 한다.
6. **잠재력:** 현재 능력의 상한 역할(현재 ≤ 잠재 유지). 젊은 선수는 잠재력이 높을수록 성장에 유리. 오래 활약한 30대가 상승하면 잠재 상한을 현재 능력과 같게 올려 모순을 방지하되, 기존 확정된 잠재력을 사용자 승인 없이 **감소**시키지 않는다. 100점 초과 금지. 향후 노쇠화 및 잠재력 수정의 세부 확률은 별도 설계 전까지 미구현.
7. **부상 연계:** 기존 v4.56 부상 중 출전 제한/피로도를 유지. 복귀 직후에는 먼저 폼/컨디션 저하로 반영하고, 부상만으로 기본 능력치를 즉시 영구 감소시키지 않는다. 장기간 회복 후 경기력 저하가 여러 평가 구간에서 확인되면 원칙 4를 적용.
8. **리그 공정성:** 한화와 나머지 9개 구단에 같은 계산 주기/기준을 사용하고, AI 선수도 경기 기록이 실제로 진행된 범위에서만 변화한다. 다른 구단의 모르는 기록을 생성해 소급 패치하지 않는다.
9. **변경 로그 필수:** 매 평가 때 `날짜/구단/선수/연 나이/평가 표본/평가 전 능력/폼/증감/평가 후 능력/사유`를 저장 대상으로 기록한다. 기록이 없어 평가 불가하면 능력치 보존.
10. **사용자 승인 경계:** 기존 승인 없는 경기·계약·지출·로스터 확정 금지 유지. 다만 사용자가 **경기 진행을 승인한 경우** 그 진행 범위 안에서의 폼·능력치 평가는 v4.58 게임 규칙에 따라 자동으로 반영할 수 있으며, 변경 결과를 경기 종료 화면에 공개한다.

# E. v4.60.4 누적 추가 — 2026 KBO 10구단 외국인·아시아쿼터 40명 게임 능력치 평가표

> **최신 통합 기준: v4.60.4.** 위 v4.60.3 마스터의 원문을 **바이트 변경 없이 그대로 앞부분에 보존**하고 이 절만 추가했다. 앞부분의 옛 버전 표제는 역사 문서로서 보존한 것이며 현재 버전은 v4.60.4이다.
>
> **평가 시점과 의미:** 이 표는 2026-11-22 대화에서 제시한 **2026 개막 시점 기준 40명의 능력/잠재 제안표를 숫자 그대로 기록**한 것이다. 공식 KBO 능력치가 아니며, 실제 선수 성적이나 계약 상태를 새로 검증한 표가 아니다. 시즌 중 교체 외국인(예: 브루스 짐머맨)은 개막 40명 목록에 포함하지 않으며 별도 후보로 유지한다.
>
> **저장 ≠ 확정 적용:** 한화 페라자 87/87만 기존 확정 수치이다. 나머지 39명의 수치는 모두 **제안**, 10개 구단 전체의 확정 능력치를 덮어쓰지 않는다. 특히 한화 에르난데스/화이트/왕옌청의 게임상 계약 상태는 **미확인**이고 영입 확정이 아니다.

## E1. 능력치 평가 해석 (100점 만점)
- 95~100: MVP·리그 최고 수준 / 90~94: 리그 최상위 / 85~89: 강한 핵심 전력 / 80~84: 우수한 주전·선발 / 75~79: 평균 이상 / 70~74: 1군 평균권 / 60~69: 백업·검증 단계 / 59 이하: 육성 대상.
