[필수 패치: 게임 시작 화면 / 새 게임과 이어하기 분리]
게임 웹앱에 진입하면 기존 한화 대시보드로 바로 들어가지 말고 다음의 초기 타이틀 화면을 가장 먼저 렌더링해.
- 타이틀: KBO GM 2026, 야구 게임처럼 깔끔한 다크/라이트 대응 반응형 UI, 구단 로고는 사용 권한이 있는 실제 로고만 이용.
- 큰 버튼 두 개: [새 게임 시작] [기존 게임 이어하기], 작은 버튼 [세이브 불러오기] [설정].
- '기존 게임 이어하기'를 누르면 아래 보존된 CURRENT_STATE.json을 복원해 한화 이글스 2026 6승3패, 9/144경기, 리그2위, 29인/27인, 미지급 43.30억 원 + $1,800,000 게임 대시보드로 간다. 경기 자동 실행 금지.
- '새 게임 시작'을 누르면 구단 선택 화면(2026 KBO 10개 구단: LG, 한화, SSG, 삼성, NC, KT, 롯데, KIA, 두산, 키움)을 열고, 시즌 2026, 구단 로고+구단명, 사용자 GM 이름(선택)을 설정한 뒤 [커리어 시작]을 클릭해야 새 상태를 생성한다.
- 새 게임은 시작 시 0승0패, 0/144경기, 로스터/재정/계약은 별도 NEW_GAME_INITIAL_TEMPLATE 스키마와 구단별 확정 근거가 있는 값만 사용하며 확인되지 않은 값은 미확정으로 둔다. 기존 한화 중도 세이브를 새 게임 시작 값으로 복제하지 않는다.
- 첫 커리어 흐름: 취임식 -> 감독·코치 -> 선수단 전력 분석 -> 전력 보강 -> 특별 신인 드래프트 -> 개막 엔트리 -> 정규시즌. 이미 확정된 세이브의 내역과 새 게임 미확정 진행을 혼합하지 않는다.
- 새 게임 생성 전 기존 세이브를 '보존된 커리어' 슬롯에 아카이브로 남긴다. 새 게임 생성은 기존 CURRENT_STATE.json/45경기 원장/경기 기록을 덮어쓰지 않는다.
- 저장 슬롯 분리: careerId 기반 독립 저장소. 마지막 플레이한 커리어 목록과 시즌/구단/승패를 '이어하기'에서 선택 가능. 자동 저장은 승인된 변경 직후에만, 내보내기/가져오기 JSON 및 백업 지원.
- 세이브가 없는 새 설치에서는 [이어하기]를 비활성화하거나 '불러올 세이브 없음'을 보여주고 새 게임으로 유도한다. 번들에 포함된 한화 기존 세이브는 '보존된 한화 커리어'로 import 가능한 초기 슬롯에 제공한다.
- [새 게임 시작]은 절대 즉시 경기 시뮬레이션, 무단 계약, 현금 지출을 실행하지 않는다.
- 새 게임 선택/세이브 읽기/타이틀 표시를 실제 동작하는 UI+상태 전이로 구현하라. 그림만 그리거나 텍스트로 설명하는 것이 아니다.
- 검증: 최초 실행 시 타이틀 화면; 새 게임 진입 시 구단 선택; 취소 시 기존 상태 무변경; 이어하기 선택 시 6승3패 기존 한화 상태 복구; 새 게임 생성 뒤에도 이전 세이브 복원 가능.

Google AI Studio Build 모드에서 작동하는 KBO GM 2026 시뮬레이터 웹앱을 제작해줘.
첨부 마스터 세이브(md), CURRENT_STATE.json, 45경기 원장(json), 9개 구단 개인기록(json), 타이틀 순위(json)를 정독하고 게임 데이터로 import해줘. 이전 ChatGPT의 대화형 UI를 그림으로 흉내 내는 것이 아니라 실제 상태를 가진 작동하는 웹앱을 개발해줘.

기술: React + TypeScript. 모바일과 데스크톱 모두 대응. 게임 로직은 UI와 독립된 pure TypeScript 함수로 두고 결정적인 seed 기반 RNG로 재현 가능한 가상 경기를 계산. 팀·선수·경기·시리즈·계약·재정·부상·성장·타이틀 데이터를 구조화하며 localStorage/IndexedDB 또는 제공되는 저장소를 통해 재접속 시 상태 유지. 세이브 JSON 내보내기/가져오기와 과거 백업/복원 기능 필요. 프리뷰/조회는 상태 변경 금지.

첫 화면: KBO GM 2026 타이틀 시작 화면(새 게임 시작 / 기존 게임 이어하기 / 세이브 불러오기 / 설정). 이어하기를 눌렀을 때 한화 공식 로고의 사용이 가능한 경우 출처 준수, compact GM 대시보드. 시즌 6승3패, 9/144, 리그2위, 다음 시리즈 시작 전. 2026 한화 감독 류지현, 타순 9명 세로 표시. 화면 메뉴: 3연전 진행, 10구단 순위, 선수 상세 기록, 리그 타이틀 TOP10, 선수단, 계약·재정, 기록·부상, 세이브/불러오기. 정규시즌은 3경기 한 번에(잔여경기만), 포스트시즌은 한 경기씩. 각 구단 경기와 개인 성적 동시 갱신. 경기 후 간결한 요약+상세 기록 탭.

매우 중요한 데이터 불변성: 과거 45경기 점수/승패, 한화 6승3패 및 확정 개인 기록·능력/잠재력·트레이드·계약·재정·11명 신인·외국인 계약 절대 임의 변경 금지. 합성 타 구단 개인 기록은 게임 내 가상 기록으로 라벨. 원본에서 없는 부분은 '미집계/미확정'으로 남기고 실존 선수처럼 보이는 가짜 이름 생성 금지. 원본 마스터는 보관용 immutable source로 보존. 게임 엔진 구현과 기존 텍스트 규칙 파일은 별개임을 구분.

첫 구현을 할 때 타이틀 시작 화면부터 렌더링해. 기존 세이브는 이어하기로 진입할 때만 읽어 활성화해. 데이터 누락 및 계산 정합성(전 구단 총승=총패, 경기마다 양 팀 1개 결과, 투수/타자 공식 계산)을 검증하는 테스트도 작성해. 사용자가 '경기 시작' 버튼을 누르기 전까지 어떤 경기나 재정 지급도 발생시키지 마.
